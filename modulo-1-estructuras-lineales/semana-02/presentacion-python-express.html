while i <= 5:
    print(i)

Úsalo cuando no sabes de antemano cuántas veces vas a repetir (ej. hasta que una pila quede vacía).

Control de flujo · 3

for — recorrer una secuencia

for i in range(5):        # 0, 1, 2, 3, 4
    print(i)

for elemento in [10, 20, 30]:
    print(elemento)

for indice, valor in enumerate(["a", "b", "c"]):
    print(indice, valor)   # 0 a, 1 b, 2 c

Úsalo cuando sí sabes qué vas a recorrer: una lista, un rango, los caracteres de un string.

POO · 1

De función suelta a clase

Antes (función)

def es_mayor(edad):
    return edad >= 18

es_mayor(20)

Con clase (objeto)

class Persona:
    def __init__(self, edad):
        self.edad = edad

    def es_mayor(self):
        return self.edad >= 18

p = Persona(20)
p.es_mayor()
POO · 2

self — "este objeto en particular"

  • self es el objeto sobre el que se llamó el método. Python lo pasa automático.
  • __init__ es el constructor: corre una vez, al crear el objeto con Clase(...).
  • self.dato = valor guarda un atributo — vive mientras el objeto exista.
  • Cada objeto tiene su propia copia de los atributos: p1 = Persona(20) y p2 = Persona(30) no se pisan entre sí.
POO · 3

Así se ve una estructura de datos real

class Pila:
    def __init__(self):
        self._datos = []          # atributo: la lista interna

    def push(self, dato):          # método: modifica el objeto
        self._datos.append(dato)

    def pop(self):
        if not self._datos:
            raise IndexError("pila vacía")
        return self._datos.pop()

    def __str__(self):              # método especial: usado por print()
        return f"Pila: {self._datos}"
Recursión · 1

La plantilla de toda función recursiva

def funcion(problema):
    if es_caso_base(problema):        # 1. CASO BASE — detiene la recursión
        return valor_directo

    return combinar(                   # 2. CASO RECURSIVO — problema más chico
        parte,
        funcion(resto_del_problema)
    )

Sin caso base: recursión infinita → RecursionError.

Recursión · 2

Ejemplo: factorial

def factorial(n):
    if n == 0:          # caso base
        return 1
    return n * factorial(n - 1)   # caso recursivo

factorial(3) se resuelve así:

factorial(3)
= 3 * factorial(2)
= 3 * (2 * factorial(1))
= 3 * (2 * (1 * factorial(0)))
= 3 * (2 * (1 * 1))
= 6
